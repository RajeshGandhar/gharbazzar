## The five strategic calls that need your sign-off

1. **NCR scope-down at launch.** NCR = student housing only; general NCR buy/rent waits for Braj dominance + funding. (12)
2. **Supply before revenue.** Free until per-city liquidity gates; monetization is a switch, not a launch feature. (05§0)
3. **Assisted listing is an ops function.** WhatsApp-based "we list it for you" is a launch requirement. (02§A2)
4. **Launch timing = admission season.** Go-live reverse-engineered from the April–July window; slip ⇒ January intake, never a dead-month launch. (12)
5. **Contact-gating model.** Sellers are monetized; seekers never pay for contacts. (05§2)

## Revision protocol
These are living documents. Changes land via the feature-request protocol in `AGENTS.md` (14-step review → doc update → implementation). No silent drift: if reality diverges from a blueprint doc, the doc gets amended in the same change.
